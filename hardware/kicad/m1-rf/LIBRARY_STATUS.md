# Local KiCad library

## SSOP-24_Si4735-D60_P0.635mm

A project-local footprint source now exists at:

`POR10.pretty/SSOP-24_Si4735-D60_P0.635mm.kicad_mod`

It encodes the **verified 0.635 mm pitch and 24-pin numbering/orientation** so the project no longer depends on an incorrect 0.65 mm generic footprint.

### Important

The current pad length/width and body/courtyard geometry are explicitly **PROVISIONAL**. They are intentionally marked as such in the footprint itself. They must be replaced/confirmed from the exact manufacturer mechanical package drawing before PCB fabrication or M1.3 PASS.

This is now a real KiCad footprint artifact, but not yet a fabrication-qualified land pattern.
